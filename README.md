#  Cricket Analytics & Player Performance Intelligence Dashboard

##  Project Overview

This project analyzes cricket player performance across ODI, T20, and Test formats using batting, bowling, and fielding statistics.

The objective is to transform raw cricket datasets into structured analytical datasets and generate meaningful insights through data cleaning, feature engineering, exploratory data analysis (EDA), and interactive dashboards.

---

##  Objectives

- Clean and preprocess raw cricket datasets
- Perform feature engineering for advanced performance metrics
- Analyze batting, bowling, and fielding performance
- Build interactive dashboards using Tableau/Power BI
- Generate insights for player comparison and performance evaluation
